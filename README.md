## Aim

To implement Erosion and Dilation using Python and OpenCV.

## Algorithm

### Step 1:
Import the necessary packages such as OpenCV and NumPy.

### Step 2:
Create a blank image and generate text using `cv2.putText()`.

### Step 3:
Create a structuring element (kernel) for morphological operations.

### Step 4:
Apply erosion to shrink the white regions in the image.

### Step 5:
Apply dilation to expand the white regions in the image and display the outputs.

---

## Output

### Input Image
- Displays the generated text image.

### Eroded Image
- Displays the image after erosion operation where the text becomes thinner.

### Dilated Image
- Displays the image after dilation operation where the text becomes thicker.

Thus, the generated text image is successfully eroded and dilated using Python and OpenCV.
